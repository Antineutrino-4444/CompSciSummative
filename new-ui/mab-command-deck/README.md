# MAB Command Deck

A standalone UI prototype for Mutually Assured Blocks.

Open `index.html` in a browser to view it. It does not replace or modify the
existing Java/Swing UI. The prototype is intentionally separate so the current
game remains untouched while this explores a cleaner command-deck direction.

The surface uses canvas for the live boards, radar, and background motion, and
DOM controls for command interaction.
