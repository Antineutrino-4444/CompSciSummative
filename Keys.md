# Key Bindings — Controls That Need Calibration

## Player 1 (11 actions)
Used for: Normal Tetris, MAB PvE, and the left station in local PvP.

| # | Action | Default Key | Notes |
|---|--------|-------------|-------|
| 1 | Move Left | ← (Left Arrow) | Also navigates left in menus/overlays |
| 2 | Move Right | → (Right Arrow) | Also navigates right in menus/overlays |
| 3 | Move Down | ↓ (Down Arrow) | Soft drops in game; navigates down in menus |
| 4 | Move Up | ↑ (Up Arrow) | Navigates up in menus/overlays |
| 5 | Hard Drop | Space | Hard drops in game; confirms/activates in menus |
| 6 | Rotate Clockwise | X | |
| 7 | Rotate Counterclockwise | Z | |
| 8 | Hold | C | |
| 9 | Pause | P | |
| 10 | Active Doctrine | Q | |
| 11 | Exit Stage | Escape | Force-exits the current stage back to menu |

## Player 2 (8 actions)
Used for: the right station in local same-keyboard PvP only.

| # | Action | Default Key | Notes |
|---|--------|-------------|-------|
| 1 | Move Left | J | Also navigates left in overlays |
| 2 | Move Right | L | Also navigates right in overlays |
| 3 | Move Down | K | Soft drops in game; navigates down in overlays |
| 4 | Move Up | I | Navigates up in overlays |
| 5 | Hard Drop | Enter | Hard drops in game; confirms/activates in overlays |
| 6 | Rotate Clockwise | O | |
| 7 | Rotate Counterclockwise | U | |
| 8 | Hold | ; (Semicolon) | |

---

## Notes
- Player 2 does not have Pause, Active Doctrine, or Exit Stage — those are Player 1 / shared actions.
- Move Left/Right/Up/Down and Hard Drop double as menu/overlay navigation and confirm — no separate nav bindings needed.
- The same key may be bound to multiple actions within the same player.
- Duplicate keys across Player 1 and Player 2 are rejected to prevent cross-player interference.
- Modifier keys (Shift, Ctrl, Alt, Meta, CapsLock, etc.) are valid standalone bindings.
