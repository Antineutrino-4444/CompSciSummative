# Key Bindings - Controls That Need Calibration

## Player 1 (11 actions)
Used for: Normal Tetris, MAB PvE, and the left station in local PvP.

| # | Action | Default Key | Notes |
|---|--------|-------------|-------|
| 1 | Move Left | A | Also navigates left in menus/overlays |
| 2 | Move Right | D | Also navigates right in menus/overlays |
| 3 | Move Down / Soft Drop | S | Soft drops in game; navigates down in menus |
| 4 | Move Up | W | Navigates up in menus/overlays |
| 5 | Hard Drop / Confirm | R | Hard drops in game; confirms/activates menus and overlays |
| 6 | Rotate Clockwise | T | Q is reserved for MAB active commands |
| 7 | Rotate Counterclockwise | F | |
| 8 | Hold | E | |
| 9 | Pause | K | |
| 10 | Exit Stage | Z | Force-exits the current stage back to menu |
| 11 | Reset | X | Resets the active build/match where reset is supported |

---

## Player 2 (local PvP)
Used for: the right station in local same-keyboard PvP only.

| # | Action | Default Key | Notes |
|---|--------|-------------|-------|
| 1 | Move Left | Left Arrow | Also navigates left in overlays |
| 2 | Move Right | Right Arrow | Also navigates right in overlays |
| 3 | Move Down / Soft Drop | Down Arrow | Soft drops in game; navigates down in overlays |
| 4 | Move Up | Up Arrow | Navigates up in overlays |
| 5 | Hard Drop / Confirm | P | Hard drops in game; confirms/activates menus and overlays |
| 6 | Rotate Clockwise | U | |
| 7 | Rotate Counterclockwise | O | |
| 8 | Hold | I | |
| 9 | Pause | Unbound | Pause is Player 1 / shared only |
| 10 | Exit Stage | Z | Shared exit key |
| 11 | Reset | J | Resets/restarts the local PvP match |

---

## Notes
- Hard Drop / Confirm is the Confirm button across the UI.
- Move Left/Right/Up/Down and Hard Drop double as menu/overlay navigation and confirm; no separate nav bindings are needed.
- The same key may be bound to multiple actions within the same player.
- Duplicate keys across Player 1 and Player 2 are rejected to prevent cross-player interference, except shared Exit Stage and Reset keys.
- Modifier keys (Shift, Ctrl, Alt, Meta, CapsLock, etc.) are valid standalone bindings.
