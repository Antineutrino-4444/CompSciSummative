DESIGN NOTES

Layout (1366×768).
  • Top row 88px — per-side stage banner + central DEFCON ladder.
  • Middle row 1fr — bay (144px) + board + ops mid (224px) + board + bay (144px).
  • Bottom row 96px — per-side tactical strip + central mode plate.
  • Boards use aspect-ratio 10/20; cells are ~26px in the reference frame.
Symmetry rule.
  • P1 and AI/P2 surfaces are identical components, mirrored. PvP and PvE differ only in the title text on the right banner ("STATION AI :: HEURISTIC-3" vs "STATION P2 :: COMMANDER") and the mode plate copy. Both bays are always rendered.
State language (matches brief §10).
  • BUILD CHARGE / NUKE READY / INCOMING NUKE / INTERCEPT FIRED / LAUNCH FIRED / IMPACT RESOLVED — driven entirely by the stage snapshot per side. Banners independently render their own state.
State→color mapping.
  • BUILD = cyan / CRT. READY = electric green with slow pulse. INCOMING = red with fast pulse and red lamp blink. INTERCEPT = amber. LAUNCH = magenta. IMPACT = muted gray. The pulsing red on incoming is the single most important visual.
What's deferred to the implementer.
  • Real-time animation polish on the radar pips, missile-trajectory lines between boards, perfect-clear celebrations, and topped-out board freeze frame. This mockup represents the steady-state of each banner state, not the transitions.
  • The DEFCON ladder is a derived indicator — define it as: 5 = both safe; 4 = either side ready; 3 = either side launching; 2 = active in-flight threat; 1 = simultaneous threats.
  • Controls help is intentionally absent from the steady UI. Bind it to a key (e.g. ?) that opens an overlay similar to the upgrade modal.
